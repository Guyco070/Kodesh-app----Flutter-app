# Fonts

Downloaded from Google Fonts. All four families are under the SIL Open Font
License 1.1 (https://openfontlicense.org), which allows bundling them in the app.

| Family | Used for |
|---|---|
| Heebo | All UI text |
| Frank Ruhl Libre | Prayer texts and the Omer count |
| Cormorant Garamond | The "KODESH" wordmark |
| Jost | The wordmark tagline |
